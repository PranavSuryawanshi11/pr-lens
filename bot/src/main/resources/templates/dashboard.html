Install PR-Lens on Your Repositories

Click below to open GitHub and select the repositories you want PR-Lens to monitor (e.g. yash1648/SSDCVE or All Repositories). GitHub will automatically grant PR-Lens native permissions to triage, review, merge, and close PRs.

How CodeRabbit-Style Automated Merging Works
1️⃣
Zero-Config Install
Any user installs PR-Lens onto their personal or org repository in 1 click. No tokens pasted into .env, no collaborator invites.
2️⃣
Automated PR Triage
When a PR is opened, GitHub sends an event with an installation ID. PR-Lens runs security and LLM diff analysis.
3️⃣
1-Click Merge / Close
Clicking "Accept" in email directly merges the PR on GitHub via native write token. Clicking "Reject" directly closes it.
1-Click GitHub App Creator (Official GitHub Manifest Flow)
Need to register your own official GitHub App? Click below and GitHub will open with all permissions (Pull requests: write, Issues: write, Webhooks) pre-filled automatically!

When you click Create on GitHub, PR-Lens automatically registers the app, saves your private key, and immediately redirects you to install it on your repositories!
